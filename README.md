# Sound Manager

Плагин для управления звуками в игре **Counter-Strike: Source v34**.

## Описание

Позволяет игрокам гибко настраивать, какие звуки они хотят слышать, а какие — заглушить.

## Требования

- **Counter-Strike: Source v34** (Source SDK 2006)
- **Metamod:Source** и **SourceMod 1.12 или выше**
- DHooks

> ⚠️ **Важно:** на SourceMod 1.11 плагин может вызывать краш сервера из-за известной ошибки в DHooks. Подробнее: [SourceMod issue #2282](https://github.com/alliedmodders/sourcemod/issues/2282)

## Команды

| Команда | Описание |
|---|---|
| `!snd` | Открыть меню управления звуками |
| `!sound` | То же самое |
| `!sounds` | То же самое |
| `!music` | То же самое |
| `!stopmusic` | То же самое |
| `!stopsounds` | То же самое |

## Предупреждение

Если звук уже начал проигрываться, остановить его можно только командой `snd_restart` в консоли. Возможно, в будущем будет добавлена возможность останавливать активные звуки без использования этой команды.

## Известные проблемы

- На SourceMod 1.11 возможно падение сервера при подключении игрока или выборе пункта меню из-за ошибки в DHooks: [issue #2282](https://github.com/alliedmodders/sourcemod/issues/2282). Решение — обновиться до SourceMod 1.12+.
